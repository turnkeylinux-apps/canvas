## Source and dependency decision

Debian packages are preferred. Debian Trixie supplies Node.js 20, PostgreSQL,
Redis and the native build libraries; Apache and Passenger come from the
inherited Rails appliance plan. Trixie renamed the XML Security runtime for the
64-bit `time_t` transition, so the package plan uses Debian's `libxmlsec1t64`
with `libxmlsec1-dev` and does not request the removed Bookworm package name
`libxmlsec1`.

Debian does not package Canvas LMS. The appliance therefore installs the
official Canvas production release identified by the `prod` branch at commit
`44bfdc264d5fe6a942ebdb5f10a0eb63ee04df3a`, whose source tree is
`dd2a9caa6afe683108a493a13c32340e1b3ac5e6`. The downloaded commit archive
must match SHA256
`2ca116f8a130b970c7b945fd547e760bdb8e7b8d0ea4c1c63f07222fd874009c`.
The commit is the official production merge for stable release 2026-04-22.

The official RCE API is likewise absent from Debian and is pinned to commit
`e076fe28a09f4e41058da0983b5ef2c809123d9f`, tree
`4a2e99c1efccf0011215bb074065a0859135a132` and archive SHA256
`1b36c2231c09d406053c92fde9d805211e538265e8d01827477a3ce9187c0495`.

Canvas requires Ruby 3.4.1 or newer within Ruby 3.4. The inherited TurnKey
Rails build installs Ruby 3.4 through its maintained ruby-build path. Debian's
`yarnpkg` is Yarn 4.1 and does not satisfy the Canvas Yarn Classic lock and
install contract. The inherited Rails build therefore installs Yarn Classic
from Yarn's signed official APT channel. The exact test refreshed only that
source, verified the signed APT metadata and found candidate `1.22.22-1`.
Bundler 2.6.7 and all Ruby, JavaScript and RCE dependencies remain locked by
the verified source trees.

### Verified compatibility corrections

The pinned Canvas `prod` tree has one `@instructure/platform-alerts` import but
does not include that package in `package.json` or `yarn.lock`. Official Canvas
commit `9f8cd4be107659b17a29a28dc553f9453c21da4a` fixes the release by restoring
the import from the existing `@canvas/alerts/react/FlashAlert` module. The
appliance applies that one-line official fix, verifies patch SHA256
`2a46919cd35b598ab0c7e4d2b6eeaf6138253fde7107407d800c83f65d88fc31`,
and records both identities in installed provenance. The updater accepts a
candidate only when it applies this verified fix or upstream already contains
the correction.

The pinned official RCE lock metadata incorrectly marks required module
`dev-null` as development-only. Production `npm ci` omits it and the official
preload then fails. The appliance applies the minimal lock metadata correction
and verifies patch SHA256
`bcf60f9a304e9311dfea6c843f5bafbaf8ede812668d33523e1cceb818068413`.
Passenger 6 loads CommonJS startup files, while the upstream RCE entry point
uses top-level `await`. The verified launcher imports the ordered production
preload and server modules without top-level `await`, and Apache sets the
Passenger user and group to `www-data`. Launcher SHA256 is
`6c20617d717b2a4af2ae8903e7785e5efe7a0e124f1a4cd6c12bfb9855a87299`.
The updater validates both RCE compatibility artifacts or accepts an upstream
candidate that no longer needs the dependency correction.

## Deferred issues

- MEDIUM: Upstream recommends at least 8 GB RAM for production asset
  compilation. Small systems can run Canvas after assets are built, but an
  administrator should provision update-time memory according to upstream
  production guidance.
- MEDIUM: The official RCE project publishes maintained code on `master`
  between version tags. The appliance pins an exact commit and tree and exposes
  any newer official branch head through the supervised updater.
- LOW: The Docker rootfs gate does not exercise installer, kernel or hardware
  behavior. The Docker kernel rejects the appliance hostname firstboot call
  and `systemd-sysctl`; application services and normal user flow were checked
  explicitly.
- LOW: The pinned official source names the OpenDyslexic bold italic face
  `OpenDyslexic-BoldItalic.woff2`, while its shipped file is
  `OpenDyslexic-Bold-Italic.woff2`. Only users who select OpenDyslexic and view
  bold italic text encounter the browser font fallback; the regular, italic,
  bold and mono faces are present. This is an upstream asset-name mismatch.
- LOW: The pinned official SpeedGrader stylesheet references absent legacy
  image `/images/canvas/header_canvas_logo.png`. If the legacy
  `#eg-canvas-logo` element is rendered, its decorative background is missing;
  SpeedGrader function and the current Canvas login/course flow do not depend
  on that image. The official source archive omits it.
